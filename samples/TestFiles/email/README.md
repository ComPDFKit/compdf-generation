# Email sample fixtures

- example.eml: synthetic UTF-8 multipart email, CID GIF, Bcc, and a binary attachment (00 01 02 03 ff fe). All addresses use example.test.
- synthetic_ansi.msg, synthetic_nested.msg, synthetic_native_rtf.msg: CC0-1.0 fixtures copied from pdf_generation_cpp/tests/email2html/fixtures/msg at 1bb1522. The core fixture README dedicates these synthetic fixtures to CC0-1.0. They cover CP1251 ANSI MAPI, an embedded MSG, and native RTF fallback.

These files are synthetic test data, not customer emails. The sample reads them directly. The EML created for this sample is also dedicated to CC0-1.0.
